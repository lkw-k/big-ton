사용자가 견적을 받으려는 물품: <item>

사용자의 인터뷰 답변:
<answers>

답변에서 요구 조건을 추출해 JSON 객체 하나로만 답하라. 설명, 코드 블록 없이 JSON만 출력한다.
- 답변 목록에 없는 필드, 답변에서 값을 알 수 없는 필드는 반드시 null. 추측하거나 0, 빈 문자열로 채우지 않는다.
- budget은 원 단위 정수, due_date는 YYYY-MM-DD, need_install은 true/false, quantity는 정수, notes는 문자열.

{"item": "<item>", "budget": null, "due_date": null, "need_install": null, "quantity": null, "notes": null}
